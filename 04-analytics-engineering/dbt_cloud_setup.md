# How to setup dbt cloud with bigquery
[Official documentation](https://docs.getdbt.com/tutorial/setting-up)

## Создание учетной записи сервиса BigQuery
Для подключения нам понадобится JSON-файл учетной записи сервиса, сгенерированный bigquery:
1. Откройте мастер создания учетных записей [BigQuery credential wizard](https://console.cloud.google.com/apis/credentials/wizard), чтобы создать учетную запись сервиса в вашем проекте такси.

<td> <img src="https://user-images.githubusercontent.com/4315804/152141503-1ad64131-e867-47bf-905e-ee1d7115616c.png" style="width: 450px;"/> </td>
</tr></table>

2. Вы можете либо предоставить учетной записи определенные роли, либо просто использовать bq admin, поскольку вы будете единственным пользователем как учетной записи, так и данных.

Примечание: если вы решите использовать определенные роли вместо BQ Admin, некоторые пользователи сообщили, что им необходимо добавить роль зрителя, чтобы избежать ошибок отказа в доступе.

3. Теперь, когда учетная запись службы создана, нам нужно добавить и загрузить JSON-ключ. Перейдите в раздел "Ключи", выберите "Создать новый ключ". Выберите тип ключа JSON, и после нажатия на кнопку "Создать" он сразу же будет загружен для использования.

## Создание проекта в облаке dbt
1. создайте учетную запись dbt cloud на [их сайте](https://www.getdbt.com/pricing/) (бесплатно для одиночных разработчиков)
2. после входа в dbt cloud вам будет предложено создать новый проект

Вам понадобятся:
- доступ к вашему хранилищу данных (bigquery - настраивается на неделях 2 и 3)
- доступ администратора к вашему репозиторию, где будет находиться проект dbt.

 _Примечание: Чтобы показать создание проекта с нуля, я создал новый пустой репозиторий только для этого недельного проекта. 

![image](https://user-images.githubusercontent.com/4315804/152138242-f79bdb71-1fb4-4d8e-83c5-81f7ffc9ccad.png)

3. Назовите свой проект
4. выберите Bigquery в качестве хранилища данных: ![изображение](https://user-images.githubusercontent.com/4315804/152138772-15950118-b69a-45b1-9c48-9c8a73581a05.png)
5. Загрузите ключ, который вы скачали из BQ, выбрав опцию*создать из файла*. Это позволит заполнить большинство полей, относящихся к учетным данным для производства. Прокрутите страницу вниз до конца и настройте учетные данные для разработки.

_Примечание: Набор данных, который вы увидите под учетными данными разработчика, - это тот, который вы будете использовать для запуска и построения моделей во время разработки. Поскольку местоположение BigQuery по умолчанию может не совпадать с тем, которое вы указали для исходных данных, рекомендуется создать эту схему вручную, чтобы избежать многорегиональных ошибок._ 

<table><tr>
<td> <img src="https://user-images.githubusercontent.com/4315804/153844913-00769b63-3997-42d8-8c1a-1ac5ae451435.png" style="width: 550px;"/> </td>
<td> <img src="https://user-images.githubusercontent.com/4315804/152147146-db024d57-d119-4a5b-8e6f-5475664bdf56.png" style="width: 550px;"/> </td>
</tr></table>

6. Нажмите на кнопку *Тест*, после чего вы сможете продолжить настройку.

 ## Добавьте репозиторий GitHub
Примечание:_ Этот шаг можно пропустить, используя управляемый репозиторий, если у вас нет собственного репозитория GitHub для курса.
1. Выберите git clone и вставьте SSH-ключ из вашего репозитория.
 
 <table><tr>
<td> <img src="https://user-images.githubusercontent.com/4315804/152147493-2037bb54-cfed-4843-bef5-5c043fd36ec3.png" style="width: 550px;"/> </td>
<td> <img src="https://user-images.githubusercontent.com/4315804/152147547-44ab9d6d-5f3d-41a8-8f73-2d03a568e7aa.png" style="width: 550px;"/> </td>
</tr></table>

2. Вы получите ключ развертывания, зайдите в репозиторий GH и перейдите на вкладку настроек. В разделе "Безопасность" вы найдете меню *Ключи развертывания*. Нажмите на кнопку add key и вставьте ключ развертывания, предоставленный dbt cloud. Убедитесь, что установлен флажок "доступ на запись".
