### Як запустити цей проєкт
### Про проєкт
Цей проєкт базується на [dbt starter project](https://github.com/dbt-labs/dbt-starter-project) (згенерованому за допомогою команди `dbt init`).  
Спробуйте виконати такі команди:
- `dbt run`
- `dbt test`

Проєкт включає такі файли:
- **dbt_project.yml** – файл конфігурації dbt-проєкту. Якщо ви використовуєте dbt локально, переконайтеся, що профіль у цьому файлі відповідає тому, який був налаштований під час встановлення в `~/.dbt/profiles.yml`.
- **Файли `.yml` у папках models, data, macros** – файли документації.
- **CSV-файли у папці `data`** – це наші джерела даних.
- **Файли у теці `models`** – SQL-скрипти для запуску моделей, включаючи етапи **staging, core і datamarts**. У підсумку ці моделі будуть організовані за такою структурою:

### Виконання
Після встановлення необхідних інструментів і клонування репозиторію виконайте наступні команди:

1. Перейдіть у директорію проєкту через командний рядок:
   ```sh
   cd [..]/taxi_rides_ny
   ```  
2. Завантажте CSV-файли в базу даних. Це створить таблиці у вашій цільовій схемі:
   ```sh
   dbt seed
   ```  
3. Запустіть моделі:
   ```sh
   dbt run
   ```  
4. Протестуйте дані:
   ```sh
   dbt test
   ```  
   _Альтернативний варіант:_ використовуйте команду
   ```sh
   dbt build
   ```  
   для виконання трьох попередніх кроків однією командою.
5. Згенеруйте документацію для проєкту:
   ```sh
   dbt docs generate
   ```  
6. Перегляньте документацію. Ця команда запустить вебсервер з документацією, доступною за адресою [http://localhost:8080](http://localhost:8080):
   ```sh
   dbt docs serve
   ```
