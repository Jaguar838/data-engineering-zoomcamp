### Питання 1: Розуміння dbt моделі

Припустимо, у вас є наступний `sources.yaml`:
```yaml
version: 2

sources:
  - name: raw_nyc_tripdata
    database: "{{ env_var('DBT_BIGQUERY_PROJECT', 'dtc_zoomcamp_2025') }}" # myproject
    schema:   "{{ env_var('DBT_BIGQUERY_SOURCE_DATASET', 'raw_nyc_tripdata') }}" # raw_nyc_tripdata
    tables:
      - name: ext_green_taxi
      - name: ext_yellow_taxi
```

І такі змінні середовища, де виконується `dbt`:
```shell
export DBT_BIGQUERY_PROJECT=myproject
export DBT_BIGQUERY_DATASET=my_nyc_tripdata
```

Що компілюється з цього SQL-запиту?
```sql
select * 
from {{ source('raw_nyc_tripdata', 'ext_green_taxi' ) }}
```

Відповідь:
- `select * from myproject.raw_nyc_tripdata.ext_green_taxi`

### Питання 4: dbt Макроси та Jinja

Припустимо, ви працюєте з конфіденційними даними (наприклад, [PII](https://en.wikipedia.org/wiki/Personal_data)), які доступні лише вашій команді та кільком відібраним особам. Ви вирішуєте обфускувати ці дані у своїх `staging`-моделях перед передачею в `service`-рівень.

Ви створюєте макрос:
```sql
{% macro resolve_schema_for(model_type) -%}

    {%- set target_env_var = 'DBT_BIGQUERY_TARGET_DATASET'  -%}
    {%- set stging_env_var = 'DBT_BIGQUERY_STAGING_DATASET' -%}

    {%- if model_type == 'core' -%} {{- env_var(target_env_var) -}}
    {%- else -%}                    {{- env_var(stging_env_var, env_var(target_env_var)) -}}
    {%- endif -%}

{%- endmacro %}
```

І використовуєте його в `staging`, `dim_`, `fact_`-моделях:
```sql
{{ config(
    schema=resolve_schema_for('core'), 
) }}
```

Які твердження щодо цього макросу є **правильними**?
- Змінна середовища `DBT_BIGQUERY_TARGET_DATASET` є обов’язковою, інакше код не скомпілюється.
- При використанні `core`, модель матеріалізується в `DBT_BIGQUERY_TARGET_DATASET`.
- При використанні `stg`, модель матеріалізується в `DBT_BIGQUERY_STAGING_DATASET`, або за замовчуванням у `DBT_BIGQUERY_TARGET_DATASET`.
- При використанні `staging`, модель матеріалізується в `DBT_BIGQUERY_STAGING_DATASET`, або за замовчуванням у `DBT_BIGQUERY_TARGET_DATASET`.
