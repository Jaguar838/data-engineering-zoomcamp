### Question 5.
#### Which were the top pickup locations with over 13,000 in total_amount (across all trips) for 2019-10-18?

Query:
```
WITH daily_totals AS (
    SELECT 
        "PULocationID",
        SUM(total_amount) AS total_amount_sum
    FROM green_taxi_data
    WHERE lpep_pickup_datetime::date = '2019-10-18'
    GROUP BY "PULocationID"
    HAVING SUM(total_amount) > 13000
)
SELECT 
    z."Zone",
    d.total_amount_sum
FROM daily_totals d
JOIN zones z ON d."PULocationID" = z."LocationID"
ORDER BY d.total_amount_sum DESC
LIMIT 3;
```
Answer:
```
East Harlem North, East Harlem South, Morningside Heights
```

### Question 6.
#### For the passengers picked up in Ocrober 2019 in the zone name "East Harlem North" which was the drop off zone that had the largest tip?
Query:
```
WITH east_harlem_north_id AS (
    SELECT "LocationID"
    FROM zones
    WHERE "Zone" = 'East Harlem North'
),
october_trips AS (
    SELECT *
    FROM green_taxi_data
    WHERE EXTRACT(MONTH FROM lpep_pickup_datetime) = 10
      AND EXTRACT(YEAR FROM lpep_pickup_datetime) = 2019
      AND "PULocationID" = (SELECT "LocationID" FROM east_harlem_north_id)
),
max_tip_dropoff AS (
    SELECT 
        "DOLocationID",
        MAX(tip_amount) AS max_tip
    FROM october_trips
    GROUP BY "DOLocationID"
)
SELECT 
    z."Zone",
    m.max_tip
FROM max_tip_dropoff m
JOIN zones z ON m."DOLocationID" = z."LocationID"
WHERE m.max_tip = (SELECT MAX(max_tip) FROM max_tip_dropoff);
```
Results:
```
|     "Zone"     |  "max_tip" |
|  "JFK Airport" |   "87.3"   |
```
Answer:
```JFK Airport ```
